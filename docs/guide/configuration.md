# Configuration & Secrets

This page details all available environment variables, Cloudflare secrets, and KV configuration options for **Telegram Alerts Gateway**.

---

## Secrets

Secrets are sensitive credentials managed via Wrangler CLI and encrypted in Cloudflare Workers.

Set secrets using:
```bash
npx wrangler secret put <SECRET_NAME>
```

| Secret Name | Required | Description |
| :--- | :--- | :--- |
| `TELEGRAM_BOT_TOKEN` | **Yes** | Bot authentication token generated by [@BotFather](https://t.me/BotFather). |
| `TELEGRAM_CHAT_ID` | **Yes** | Numeric Chat ID of your Telegram Supergroup (starts with `-100...`). |
| `AUTH_TOKEN` | **Yes** | Master API key used to authenticate inbound requests (`x-api-key: <TOKEN>`). |
| `TELEGRAM_WEBHOOK_SECRET` | **Yes** | Random secret token used by Telegram to authenticate incoming webhook events to `/webhook`. |

::: warning Secret Security
Never commit real secrets or tokens into `wrangler.toml` or git. Always use `npx wrangler secret put`.
:::

## Environment Variables (`[vars]`)

Configurable in your `wrangler.toml` under the `[vars]` table.

```toml
[vars]
ADMIN_USER_ID = "123456789"
QUIET_HOURS_START = "23"
QUIET_HOURS_END = "07"
TIMEZONE = "America/New_York"
```

| Variable Name | Default | Description |
| :--- | :--- | :--- |
| `ADMIN_USER_ID` | *Unset* (Open to group admins) | Comma-separated list or single numeric Telegram User ID allowed to manage tokens (`/token`). |
| `QUIET_HOURS_START` | *Unset* (Disabled) | Hour of the day (0–23) when quiet hours begin. Alerts during this window are sent silently (`disable_notification: true`). |
| `QUIET_HOURS_END` | *Unset* (Disabled) | Hour of the day (0–23) when quiet hours end. |
| `TIMEZONE` | `UTC` | Timezone string (e.g. `UTC`, `America/New_York`, `Europe/London`, `Asia/Kolkata`) used to evaluate quiet hours. |
| `UNKNOWN_TOPIC_ID` | *Auto-created* | Explicit Telegram forum thread ID for unauthenticated incoming alerts. |
| `CATCHALL_TOPIC_ID` | *Auto-created* | Explicit Telegram forum thread ID for raw unrecognized payloads. |

## Cloudflare KV Bindings

The gateway requires a Cloudflare KV namespace bound to `GATEWAY_KV`.

```toml
[[kv_namespaces]]
binding = "GATEWAY_KV"
id = "a1b2c3d4e5f6..."
preview_id = "f6e5d4c3b2a1..."
```

What KV stores:
- **Topic mappings**: Caches topic name $\rightarrow$ Telegram `message_thread_id` to eliminate redundant Telegram API lookups.
- **Dynamic API tokens**: Tokens generated in chat via `/token 30d <name>`.
- **Mute states**: Topics temporarily muted via `/mute <topic> <duration>`.
