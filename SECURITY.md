# Security policy

## Supported versions

Only the latest commit on the `main` branch receives security updates.

| Version | Supported |
|---|---|
| 1.0.x on `main` | Yes |
| Older releases | No |

## Reporting a vulnerability

If you discover a potential security vulnerability in this project, do not report it in public GitHub issues.

Please report vulnerabilities privately through GitHub Security Advisories:

https://github.com/uditrajput03/telegram-alerts/security/advisories/new

Provide:
1. A description of the vulnerability.
2. Steps or scripts to reproduce the issue.
3. Potential impact of the issue.

Security reports receive a response within 48 hours. Valid vulnerabilities receive a patch before public disclosure.
